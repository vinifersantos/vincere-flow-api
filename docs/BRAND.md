# Identidade do produto

## Nome oficial

**Vincere Flow**

## Nome do repositório

`vincere-flow-api`

## Descrição curta

API de gestão comercial da marca Vincere, integrando estoque, vendas, fluxo de caixa e indicadores.

## Tagline

**Transforme movimento operacional em decisão.**

## Racional

- **Vincere** preserva a marca principal.
- **Flow** representa o encadeamento entre produto, estoque, venda, caixa e indicador.
- O nome não promete um ERP completo antes de o produto estar pronto.
- A marca pode evoluir para `Vincere Flow Web`, `Vincere Flow Mobile` e outros componentes.

## Convenções

- Produto: `Vincere Flow`
- Backend: `Vincere Flow API`
- Repositório: `vincere-flow-api`
- Package Java: `io.github.vinifersantos.vincereflow`
- Prefixo de recursos Azure: `vincere-flow`
